# 🛒 Sistema de Compras em Python (CLI)

## 📌 Descrição

Este projeto é um sistema de compras desenvolvido em Python com menu interativo no terminal (CLI).
O usuário pode cadastrar produtos, visualizar um relatório parcial e finalizar a compra com aplicação de descontos conforme a forma de pagamento.

## 🚀 Funcionalidades

* Menu interativo no terminal
* Cadastro de múltiplos produtos
* Validação de entradas (nome, preço e quantidade)
* Cálculo automático de subtotal por produto
* Visualização de relatório parcial a qualquer momento
* Cálculo do valor total da compra
* Aplicação de descontos:

  * 10% para compras a partir de R$100
  * 15% para compras acima de R$200
* Finalização da compra com resumo completo

## 🛠️ Tecnologias utilizadas

* Python 3

## ▶️ Como executar

1. Instale o Python 3 na sua máquina
2. Clone este repositório:

```
git clone https://github.com/seu-usuario/seu-repositorio.git
```

3. Acesse a pasta do projeto:

```
cd seu-repositorio
```

4. Execute o programa:

```
python nome_do_arquivo.py
```

## 🧭 Como usar

Ao executar o programa, será exibido um menu com opções:

* **1** → Cadastrar produtos
* **2** → Ver relatório dos produtos cadastrados
* **3** → Finalizar compra (aplica desconto e mostra total final)
* **0** → Sair do sistema

O usuário pode navegar livremente pelo menu até decidir finalizar ou encerrar o programa.

## 📊 Exemplo de uso

* O usuário cadastra vários produtos
* Pode visualizar o relatório parcial a qualquer momento
* Ao finalizar, escolhe a forma de pagamento
* O sistema calcula automaticamente:

  * Total da compra
  * Desconto (se aplicável)
  * Valor final
